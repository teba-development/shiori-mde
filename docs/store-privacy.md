# 栞（しおり）のプライバシーポリシー

栞は、Windows上でMarkdown文書を閲覧、編集、変換するアプリです。栞を利用するためのアカウント登録はありません。栞の開発者は、アプリの利用状況や編集した文書を収集しません。

栞は、利用者が開いた文書と、参照を許可したローカル画像を端末上で処理します。保存やエクスポートの結果は、利用者が指定した場所に書き込みます。保存が中断された場合に復元できるよう、復元記録を端末のアプリデータ領域に、バックアップを文書と同じフォルダーに保存することがあります。

文書内のWebリンクやメールリンクを利用者が開くと、Windowsの既定のブラウザーまたはメールアプリに引き渡します。リンク先では、各サービスのプライバシーポリシーが適用されます。Windows、Microsoft Store、WebView2ランタイムによるデータの取り扱いは [Microsoftのプライバシーステートメント](https://www.microsoft.com/ja-jp/privacy/privacystatement) を参照してください。

お問い合わせは、Microsoft Storeの栞の掲載ページに記載されているサポート窓口にお寄せください。
